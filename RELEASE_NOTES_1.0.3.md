# Open Nectar 1.0.3

This release makes Pikmin 2 easier to play on Android touch screens and
redesigns its Randomizer window to work like the one in Pikmin 1. Saves,
settings and texture packs carry over.

**Updating:** press **Update** in your launcher. On Android, install the new
APK over the old one.

## Pikmin 2: touch controls (Android)

* **The landing prompt on the map can be answered by touch.** When you
  pick an area on the map, the yes/no question about landing did not react
  to the touch screen. Now a **cancel** button appears in the bottom-left
  corner and a **confirm** button in the bottom-right corner.
* **The same two buttons appear in the other game menus**, so you can always
  confirm or go back with your thumbs, even where tapping an option does
  not respond.

## Pikmin 2: Randomizer window

* **Same layout as Pikmin 1.** The window now has two pages:
  * **Introduction:** a short explanation of what the Randomizer does.
    A continues, B goes back to the title screen.
  * **Randomizer Settings:** one row per option with its value in a box
    (`<  value  >`). Use the arrows to change it, or tap the left or right
    half of the box. B goes back to the introduction.
* **Seed code row:** press A to type a friend's code (on Android this opens
  the keyboard). Ctrl+C copies your code and Ctrl+V pastes one. An invalid
  code keeps your current one and shows a warning.
* **New random seed** row to roll a new seed, and a **Start** button at the
  bottom.
* **Fits on phone screens.** The window used to be too big on Android and
  was cut off; it now shrinks to fit the screen.
* The window uses Pikmin 2's own menu plates and text style.
